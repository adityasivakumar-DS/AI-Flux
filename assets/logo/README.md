# AI Flux 2.0 — Logo Assets

## Logo Variants

| File | Usage |
|---|---|
| `ai-flux-logo.svg` | Primary — light backgrounds |
| `ai-flux-logo-dark.svg` | Dark — dark backgrounds |
| `ai-flux-icon.svg` | Icon / mark only |
| `ai-flux-wordmark.svg` | Wordmark only (no icon) |

## Brand Colors

- Primary Logo: Purple `#7C3AED` + White `#FFFFFF` text on Navy `#0D0E1A`
- Dark Logo: Full color on dark background
- Monochrome: White on dark / Navy on light

## Usage Rules

- Minimum clear space: equal to the height of the "A" icon mark
- Minimum size: 120px wide (digital), 30mm (print)
- Never distort, rotate, or recolor the logo
- Never place on low-contrast backgrounds
- The sparkle/star mark is integral to the mark — do not remove it
