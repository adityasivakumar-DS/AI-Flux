| Attribute | Value |
|---|---|
| **Philosophy** | Purposeful, fluid — reflects "flowing intelligence" |
| **Default duration** | 200ms |
| **Default easing** | ease-out |
| **Interactive feedback** | spring cubic-bezier(0.34, 1.56, 0.64, 1) |
| **Entrance** | ease-out |
| **Exit** | ease-in |

---

## Accessibility

- Minimum 4.5:1 contrast for normal text (WCAG AA)
- Minimum 3:1 contrast for large text and UI components
- Focus rings: 2px `#00E5FF` (cyan) with 2px offset
- Never rely on color alone to convey meaning
- All interactive elements keyboard accessible
- Motion respects `prefers-reduced-motion`
